# SmartAttack（智攻）— 路演 PPT 制作指导

> 目标赛事：中国国际大学生创新大赛（原"互联网+"）/ 挑战杯 / 三创赛  
> 路演时长：8-10 分钟 PPT 演讲 + 1 分钟视频  
> 建议页数：20-25 页（按每页 25-30 秒估算）

---

## 一、国创赛评委的底层逻辑

评委在 10 分钟内只关心 5 个问题，你的 PPT 要逐页回答：

| 评委想问             | 你要回答               | 对应 PPT 段落   |
| -------------------- | ---------------------- | --------------- |
| **凭什么是你？**     | 发现了别人没发现的痛点 | 痛点 + 背景     |
| **你怎么解决？**     | 产品方案清晰可理解     | 产品介绍 + 演示 |
| **你比别人强在哪？** | 技术壁垒 + 竞品对比    | 技术创新 + 竞品 |
| **怎么赚钱？**       | 商业模式可行           | 商业模式 + 财务 |
| **这事能成吗？**     | 团队靠谱 + 规划清晰    | 团队 + 发展规划 |

> ⚠️ 重要提示：国创赛评委 80% 不是技术背景（投资人和企业家居多），不要陷入技术细节。用类比和画面感让人"秒懂"。

## 三、1 分钟视频制作指南

### 视频结构（精确到秒）

| 时间段 | 画面                          | 旁白                                                                             |
| ------ | ----------------------------- | -------------------------------------------------------------------------------- |
| 0-3s   | 黑屏 → Logo 亮起              | "SmartAttack，AI 驱动的 API 渗透测试平台"                                        |
| 3-10s  | 输入 Swagger URL → 点击扫描   | "只需输入你的 API 文档地址，AI 自动开始渗透测试"                                 |
| 10-40s | **攻击飞线动画** ← 最核心画面 | "5 个 AI Agent 从鉴权、数据、逻辑、注入四个维度并发攻击——实时呈现每一次攻击路径" |
| 40-50s | 漏洞列表弹出 + 风险等级       | "30 秒内发现所有漏洞，精准定位，零误报"                                          |
| 50-55s | PDF 报告一键导出              | "一键生成专业安全报告"                                                           |
| 55-60s | Logo + 一句话                 | "SmartAttack — 让每个 API 都安全"                                                |

### 视频制作要点

- **核心画面**：`AttackVisualization.jsx` 的飞线动画（这是最炫的部分，占视频至少 1/3 时间）
- **配乐**：科技感电子音乐（Artlist/EpidemicSound 上找 "tech/corporate" 类）
- **节奏**：前 3 秒抓住注意力，中间 30 秒展示核心技术，最后 5 秒留品牌
- **不要**：大段文字、静态截图、读 PPT
- **要**：动态画面 + 简短旁白 + 字幕

## 四、PPT 设计规范

### 配色方案

```
主色：  #1a56db (深蓝 — 科技、安全、信任)
辅色：  #10b981 (绿色 — 安全、通过)
强调色：#ef4444 (红色 — 漏洞、警示)
背景：  #ffffff 或 #f8fafc
文字：  #1e293b (深灰，不用纯黑)
```

### 字体建议

- 标题：**思源黑体 Bold** 或 **微软雅黑 Bold**
- 正文：**思源黑体 Regular** 或 **微软雅黑**
- 数字/数据：**DIN Alternate** 或 **Montserrat**

### 排版原则

```
每页只讲一件事
大标题 < 15 字
每页正文 < 30 字（多用图表替代）
关键数字要大、要突出
善用 emoji 做视觉锚点（但不是非主流的）
```
